# Project Brief: AI-Powered French Learning Platform

## Core Mission
The primary objective of this project is to transform an existing quiz-based educational platform into a state-of-the-art, AI-first French language learning experience. The platform will provide personalized, engaging, and effective language education through a mobile-first design and deep AI integration.

## Project Vision
To create a comprehensive language learning application that leverages artificial intelligence to deliver a personalized curriculum, a conversational AI tutor, and an advanced assessment engine. The vision is to move beyond static content and create a dynamic, adaptive learning environment that caters to the individual needs of each user.

## Current Status
The project is in the midst of **Phase 3: AI Integration**. A sophisticated backend infrastructure has been architected and partially implemented, including services for AI orchestration, dynamic content generation, and student assessment.

The immediate focus is on implementing the AI-First Dashboard (Task 3.1.D), which is the final step of the AI foundation phase and a critical blocker for enabling more advanced AI features planned in Phase 3.2.

## Key Features & Goals
-   **AI-Powered Personalization**: Deliver adaptive learning paths and content recommendations.
-   **Conversational AI Tutor**: Provide an interactive and supportive learning companion.
-   **Advanced Assessment Engine**: Offer detailed feedback and identify user weaknesses.
-   **Mobile-First UX**: Ensure a seamless and intuitive user experience on mobile devices.
-   **Gamification**: Incorporate elements like XP, levels, and achievements to motivate users.
