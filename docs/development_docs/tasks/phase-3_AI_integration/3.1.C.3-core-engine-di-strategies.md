## **Implementation Details**

### **1. Dependency Injection (DI)**

The `AIAssessmentEngine` will not create its own dependencies. Instead, they will be passed into its constructor by the `AIOrchestrator`. This promotes loose coupling and high testability.

```typescript
// server/src/services/aiAssessmentEngine.ts

// ... imports ...
import { IAssessmentStrategy, AssessmentStrategyFactory } from './assessmentStrategies';

export class AIAssessmentEngine {
  private strategyFactory: AssessmentStrategyFactory;

  constructor(
    // Injected dependencies
    private openai: OpenAI,
    private promptEngine: PromptTemplateEngine,
    private cache: CacheService
  ) {
    // The factory itself is created here, but it could also be injected.
    // It receives the injected dependencies to pass them to the strategies.
    this.strategyFactory = new AssessmentStrategyFactory(openai, promptEngine);
  }

  // ... methods
}
```

### **2. Strategy Pattern for Assessment Types**

To avoid a large, complex `switch` statement and to make the system easily extensible, we will use the Strategy pattern.

#### **a. Strategy Interface**
First, define a common interface that all assessment strategies must implement.

```typescript
// server/src/services/assessmentStrategies/IAssessmentStrategy.ts

import { AssessmentRequest, AssessmentResult } from '../../types/Assessment';

export interface IAssessmentStrategy {
  assess(request: AssessmentRequest, options?: { signal?: AbortSignal }): Promise<AssessmentResult>;
}
```

#### **b. Concrete Strategy Example: `MultipleChoiceStrategy`**
This is the simplest strategy, as it involves no AI call.

```typescript
// server/src/services/assessmentStrategies/multipleChoiceStrategy.ts

import { IAssessmentStrategy } from './IAssessmentStrategy';
import { AssessmentRequest, AssessmentResult, PersonalizedFeedback } from '../../types/Assessment';

export class MultipleChoiceStrategy implements IAssessmentStrategy {
  async assess(request: AssessmentRequest): Promise<AssessmentResult> {
    const isCorrect = this.normalize(request.userResponse) === this.normalize(request.expectedAnswer);
    
    const feedback: PersonalizedFeedback = isCorrect
      ? { message: 'Excellent!', tone: 'congratulatory', suggestions: [] }
      : { message: `The correct answer is ${request.expectedAnswer}.`, tone: 'encouraging', suggestions: ['Review the lesson material.'] };

    return {
      score: isCorrect ? 100 : 0,
      isCorrect,
      feedback,
      confidence: 'high',
      assessmentType: 'multiple-choice',
    };
  }

  private normalize(answer: string): string {
    return answer.toLowerCase().trim();
  }
}
```

#### **c. Concrete Strategy Example: `OpenEndedStrategy`**
This strategy involves an AI call and demonstrates passing the `AbortSignal`.

```typescript
// server/src/services/assessmentStrategies/openEndedStrategy.ts

import { OpenAI } from 'openai';
import { IAssessmentStrategy } from './IAssessmentStrategy';
import { PromptTemplateEngine } from '../promptTemplateEngine';
import { AssessmentRequest, AssessmentResult, OpenEndedAssessmentResponseSchema } from '../../types/Assessment';

export class OpenEndedStrategy implements IAssessmentStrategy {
  constructor(
    private openai: OpenAI,
    private promptEngine: PromptTemplateEngine
  ) {}

  async assess(request: AssessmentRequest, options?: { signal?: AbortSignal }): Promise<AssessmentResult> {
    const prompt = this.promptEngine.generateOpenEndedAssessmentPrompt(/*...*/);

    const response = await this.openai.chat.completions.create({
      model: 'gpt-4',
      messages: [{ role: 'user', content: prompt }],
      // ... other params
    }, { signal: options?.signal }); // Pass signal for cancellation

    const content = response.choices[0]?.message?.content;
    const parsed = OpenEndedAssessmentResponseSchema.parse(JSON.parse(content));

    return {
      score: parsed.score,
      isCorrect: parsed.score >= 70,
      feedback: parsed.feedback,
      confidence: parsed.confidence,
      assessmentType: 'open-ended',
      // ... other fields from parsed response
    };
  }
}
```

#### **d. Strategy Factory**
A factory will create and provide the correct strategy on demand.

```typescript
// server/src/services/assessmentStrategies/assessmentStrategyFactory.ts

import { ResponseType } from '../../types/Assessment';
import { IAssessmentStrategy } from './IAssessmentStrategy';
import { MultipleChoiceStrategy } from './multipleChoiceStrategy';
import { OpenEndedStrategy } from './openEndedStrategy';
// ... import other strategies

export class AssessmentStrategyFactory {
  private strategies: Map<ResponseType, IAssessmentStrategy>;

  constructor(openai: OpenAI, promptEngine: PromptTemplateEngine) {
    this.strategies = new Map<ResponseType, IAssessmentStrategy>([
      ['multiple-choice', new MultipleChoiceStrategy()],
      ['open-ended', new OpenEndedStrategy(openai, promptEngine)],
      // Add other strategies here
    ]);
  }

  getStrategy(type: ResponseType): IAssessmentStrategy {
    const strategy = this.strategies.get(type);
    if (!strategy) {
      throw new Error(`Unsupported response type: ${type}`);
    }
    return strategy;
  }
}
```

### **3. Core `assessUserResponse` Method**

The main engine method becomes very clean and simple. It just uses the factory to get the right strategy and executes it.

```typescript
// server/src/services/aiAssessmentEngine.ts (updated method)

async assessUserResponse(request: AssessmentRequest, options?: { signal?: AbortSignal }): Promise<AssessmentResult> {
  try {
    const cacheKey = `assessment:${request.responseType}:${request.userResponse}`;
    const cachedResult = await this.cache.get<AssessmentResult>(cacheKey);
    if (cachedResult) {
      return { ...cachedResult, metadata: { cached: true } };
    }

    const strategy = this.strategyFactory.getStrategy(request.responseType);
    const result = await strategy.assess(request, options);

    await this.cache.set(cacheKey, result, 3600); // Cache for 1 hour
    return result;

  } catch (error) {
    // ... error handling, return fallback assessment
  }
}
```

## **Review Points & Solutions**

-   **🔍 Review Point: Efficient Timeout Handling**
    -   **Concern**: AI calls can be slow. We must be able to cancel them to avoid wasting resources.
    -   **Solution**: The `AbortController` pattern is implemented. The `AbortSignal` is passed from the controller down to the strategy and finally to the OpenAI API call. This ensures the underlying HTTP request is properly terminated on timeout.
-   **🔍 Review Point: Extensibility**
    -   **Concern**: The system must be easy to extend with new assessment types.
    -   **Solution**: The Strategy pattern is ideal for this. To add a new assessment type (e.g., `pronunciation`), a developer only needs to create a new class that implements `IAssessmentStrategy` and register it in the `AssessmentStrategyFactory`. No changes are needed in the `AIAssessmentEngine` itself.
-   **🔍 Review Point: Code Reusability**
    -   **Concern**: Common logic should be reused.
    -   **Solution**: Dependencies like the `PromptTemplateEngine` and `OpenAI` client are injected into the strategies that need them, ensuring we are not creating duplicate instances. The core assessment flow is centralized in the `assessUserResponse` method, while specific logic is delegated.
